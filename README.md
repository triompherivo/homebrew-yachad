# Baibolintsika Yachad pour macOS

Baibolintsika Yachad est une application d’étude biblique pour Mac Apple Silicon et Intel, à partir de macOS 12.

## Installation

```bash
brew install --cask triompherivo/yachad/baibolintsika-yachad
```

L’application apparaît dans Applications. Si vous disposez déjà d’une bibliothèque hors ligne compatible, sélectionnez son dossier dans l’application.

## Mise à jour

```bash
brew upgrade --cask triompherivo/yachad/baibolintsika-yachad
```

Les téléchargements directs sont disponibles depuis les [versions macOS](https://github.com/triompherivo/homebrew-yachad/releases).
